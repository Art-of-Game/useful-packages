Useful Packages

This address is a Unity package registry. How to add it to a project is in the README.

To install one package with a Git URL, press + in the Package Manager window, choose Install package from git URL, and paste its URL. A URL follows the newest version. To stay on one version, add it to the end, like /14.1.0.
