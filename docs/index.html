Useful Packages

Unity packages I use in my projects, collected in one place and signed. The repo is github.com/Art-of-Game/useful-packages.

Add the registry

With the registry, each package installs and updates from the Package Manager window and brings what it needs by itself.

The quick way is to add this next to dependencies in Packages/manifest.json:

  "scopedRegistries": [
    {
      "name": "Useful Packages",
      "url": "https://art-of-game.github.io/useful-packages",
      "scopes": [
        "com.adrenak",
        "com.coffee",
        "com.cysharp",
        "com.facebook",
        "com.github-glitchenzo",
        "com.google",
        "com.netpyoung",
        "com.nosuchstudio",
        "com.playeveryware",
        "com.yasirkula"
      ]
    }
  ],

Or do it in the Unity window:

  1. Open Edit, Project Settings, Package Manager.
  2. Under Scoped Registries press + and fill in the three values below, then save.
  3. Open Window, Package Manager, choose My Registries, and install what you want.
Name
Useful Packages
URL
https://art-of-game.github.io/useful-packages
Scopes
One row for each, only for the packages you use. Press one to copy it.

Install one package with a Git URL

Press + in the Package Manager window, choose Install package from git URL, and paste its URL. A URL follows the newest version. To stay on one version, add it to the end, like /14.1.0.
