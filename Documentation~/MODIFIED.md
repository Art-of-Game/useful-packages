# Changes by Art of Game

This package was changed from the original at https://codeload.github.com/coolishbee/google-signin-unity/tar.gz/refs/tags/v1.0.0

- Named `com.google.signin` instead of `com.coolishbee.google-signin`, so it sits with the other Google packages.
- `package.json` has a longer description that names the authors.
- `package.json` names Google LLC as the author, which the original leaves out.
- `package.json` links the vendor's documentation, changelog and licence.
- `package.json` names `com.unity.external-dependency-manager` instead of `com.google.external-dependency-manager`, which its vendor has deprecated.
- Signed for the Unity organization Art Of Game, which adds `.attestation.p7m`.

Every other file is the original, under its own licence in this package.
